# 3D anatomy models

The **3D Anatomy Browser** loads the default rig from:

- **`t-pose-female-anatomy.fbx`** — Mixamo-style T-pose female anatomy (served as `/models/t-pose-female-anatomy.fbx`)

Replace this file in `public/models/` if you update the mesh, or set `NEXT_PUBLIC_CHARACTER_MODEL_URL` to any `.glb` / `.gltf` / `.fbx` URL.

Optional UV diffuse: `NEXT_PUBLIC_CHARACTER_DIFFUSE_MAP_URL`.
